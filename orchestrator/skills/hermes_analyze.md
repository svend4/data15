# Skill: hermes_analyze
## Назначение
Глубокий анализ текста, данных или темы с помощью Hermes Agent (Nous Research).
Используется для синтеза, исследования, написания отчётов.

## Когда использовать
- Нужен аналитический отчёт по теме
- Требуется синтез данных из нескольких источников
- Нужна генерация кода или документации
- Обработка результатов от openclaw_web_search

## Команда (реальный Hermes CLI)
**Команда:** `hermes --prompt "{goal}" --output json`

## Команда (MiniMax fallback)
**Команда:** `python3 hermes_llm.py "{goal}"`

## Входные параметры
| Параметр | Тип | Описание |
|----------|-----|----------|
| `goal` | str | Тема или текст для анализа |
| `openclaw_result` | str | (опционально) Данные от OpenClaw для анализа |

## Выходные данные
- `hermes_result`: строка с результатом анализа

## Пример вызова из WorkflowEngine
```json
{
  "name": "analyze_topic",
  "type": "action",
  "action": "call_hermes",
  "prompt": "Проанализируй следующие данные: {openclaw_result}"
}
```

## Примечания
- Hermes помнит контекст сессии через persistent memory
- Поддерживает 181+ встроенных навыков
- При отсутствии Hermes CLI автоматически использует MiniMax fallback
